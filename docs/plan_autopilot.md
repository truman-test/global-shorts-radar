## 1. 목표 재정의

- **1차 목표(30일)**: 영상 14개 안에 1만 뷰 이상 1개. 없으면 포맷 교체. 이것이 "500뷰 컷"을 넘는지 판정하는 진단.
- **2차 목표**: 구독자 1,000명. 전환율이 1만 뷰당 약 17명이므로 약 60만 뷰가 필요. 30일 안에는 상위 꼬리 결과이며, 달성 여부와 무관하게 루프를 계속 돌린다.
- **성공 지표(주간)**: 업로드 수, 중앙값 조회수, 최고 조회수, 1만 뷰 돌파 수, 구독자 증가, 영상별 평균 시청 비율.

## 2. 포맷 결정 (첫 14개 고정)

- **주제**: 기관사칭형 보이스피싱·AI 음성 복제·딥페이크 사기 — 2025년 피해 1조 2,578억 원, 78.6%가 기관사칭형. 한국 시청자에게 가장 직접적.
- **형식**: 15~30초 재연 + 해법. 0~3초는 피해자 시점의 전화 한 줄로 시작. 첫 프레임에 채널명과 "재연" 표시. 끝은 행동 한 줄(우리 집 암호 정하기, 전화 끊고 112).
- **목소리**: 한 채널 한 음성. Google Cloud TTS 한국어 Neural2 여성 또는 남성 1종을 30일간 고정.
- **화면**: 세로 1080×1920, 큰 자막(한 줄 5~7단어, 화면 중앙 55~78% 구간), 장면당 하나의 아이콘·타이포 카드, 배경은 단색 그라디언트 또는 Pexels 세로 질감.
- **설명란**: 재연 고지, 근거 출처 URL, "AI 음성 사용" 표기(정책상 필수는 아니지만 신뢰용), #Shorts.

## 3. 파이프라인 (레이더 → 영상 → 업로드 → 성과)

```
radar run (매일 09:10)  ─▶ story-dna export ─▶ 분석 에이전트 ─▶ import ─▶ brief
      ─▶ radar script   : 브리프 1개 → 대본 JSON (내레이션, 자막 줄, 장면, TTS용 정규화 텍스트, 출처, 고지문)
      ─▶ radar produce  : TTS(Google) → 단어 타이밍(SSML mark) → ASS 자막 → 장면 렌더(PIL) → ffmpeg 조립 → mp4 + 썸네일 프레임
      ─▶ QA 게이트       : 길이 15~45s, 한글 비율, 금지어(실명·뉴스사 캡처·피해자 특정), 출처 존재, 고지문 존재, 음성 파일 무음 검사
      ─▶ radar upload   : Data API videos.insert (private → 감사 후 public), 제목·설명·태그, containsSyntheticMedia 표기
      ─▶ radar publish-log 자동 기록
      ─▶ radar outcome  : (3일차 이후) YouTube Analytics API로 조회수·시청시간·구독 전환 수집 → winner/loser → 가중치 보정
```

사람이 남는 지점은 **둘**뿐입니다.
1. 계정 설정 1회: YouTube OAuth 데스크톱 클라이언트 생성 후 동의 1회, API 감사 신청서 제출(제가 홈페이지·개인정보처리방침 문서를 생성해 드림).
2. 감사 통과 전: YouTube Studio에서 직접 업로드(하루 1편, 약 2분: 영상 파일 끌어 놓기, `meta.json`의 제목·설명 붙여넣기, 변경·합성 콘텐츠 "예"). API로 올린 영상은 비공개로 잠겨 공개 전환이 불가능하므로, 통과 후에만 `radar upload`로 자동화.

## 4. 코드 가드레일 (모든 영상에 자동 적용)

- 첫 1초 자막 "※ 실제 사례를 바탕으로 한 재연입니다" + 설명란 고지
- 등장인물은 가명·연령대·직업군까지만. 실명·회사명은 공식 발표(경찰청·금감원 보도자료)에 있는 경우만, 그것도 출처 링크와 함께
- 뉴스 기사 캡처·방송 클립·언론 사진 사용 금지(코드에서 이미지 소스를 Pexels/Pixabay/자체 렌더로 제한)
- 공공기관 자료는 공공누리 1유형 확인 후 "출처: 경찰청, 공공누리 제1유형" 표기
- 사기 수법은 "어떻게 알아채는가" 수준까지만, 실행 절차는 묘사하지 않음(방송심의규정 38조 취지)
- 피해자 특정 가능 정보 금지, 성범죄·딥페이크 피해자 관련은 신원 암시 자체 금지(성폭력처벌법 24조)

## 5. 일정

| 단계 | 기간 | 산출물 | 완료 기준 |
|---|---|---|---|
| A. 대본 생성기 | 1~2일차 | `radar script`: 브리프→대본 JSON, 숫자·단위 정규화, 고지문, 출처 | 검증된 소재 3개의 대본 생성, QA 통과 |
| B. 제작기 | 2~4일차 | `radar produce`: TTS→자막→장면→mp4 | 3개 mp4를 사람이 봐도 어색하지 않은 수준(1차는 제가 검토) |
| C. 업로더 | 3~5일차 | `radar upload`, OAuth, 감사 신청 패키지 | 비공개 업로드 성공, 감사 제출 완료 |
| D. 자동화 | 5일차 | 작업 스케줄러에 produce+upload 추가(하루 1편) | 이틀 연속 무개입 생성·업로드 |
| E. 피드백 | 8일차~ | `radar outcome`, 주간 리포트 | 14편 시점 포맷 판정 |
