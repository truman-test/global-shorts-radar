# 30일 구독자 1,000명 계획 (2026-10-08 ~ 11-07)

목표는 **채널** 목표이고, 이 저장소는 그중 "무엇을 만들 것인가"를 매일 정해 주는 도구입니다. 영상 제작·편집·업로드는 도구 밖의 일이며, 구독자 수를 좌우하는 가장 큰 변수는 **꾸준한 업로드 빈도와 첫 3초**입니다. 아래는 도구가 책임지는 부분과 사람이 책임지는 부분을 나눈 실행 계획입니다.

## 전제 (바꾸면 계획도 바뀜)

- 새 채널 또는 구독자 100명 미만, 한국어 Shorts 전용
- 주제: "디지털 세상에서 평범한 사람이 겪는 놀랍고·이상하고·위험하고·유용한 이야기" (AI 사기, 폰 보안, 앱, 인터넷 사건)
- 업로드: **주 5~6편, 30일간 25편 이상**. 이보다 적으면 1,000명은 현실적이지 않습니다.
- 길이 30~45초, 세로, 자막 필수, 한국 기관·사례로 치환

## 주간 마일스톤 (확인 지표: YouTube Studio)

| 주 | 업로드 | 목표 구독자 | 판단 기준 |
|---|---|---|---|
| 1주 (10/8~14) | 6편 | 100 | 평균 조회수 1,000 미만이면 훅(첫 3초)부터 교체 |
| 2주 (10/15~21) | 6편 | 300 | 상위 2편의 공통점을 찾아 다음 주 소재 선택에 반영 |
| 3주 (10/22~28) | 7편 | 600 | 1편이라도 1만 뷰를 넘기면 그 소재의 후속편 2편 |
| 4주 (10/29~11/7) | 7편 | 1,000 | 미달이면 11월에 같은 루프 반복, 가중치 보정 |

## 매일 루프 (도구 ↔ 사람)

1. **자동** 09:10 `radar run` → 새 후보 수집·점수·리포트. 6시간마다 `track` → 가속 중인 영상 표시.
2. **오케스트레이터** `radar story-dna --export 10` → 분석 에이전트 → `--import` → `radar brief --top 3` → `reports/brief_*.md`
3. **사람 (10분)** 브리프 1번 소재의 근거 출처를 열어 확인 → `radar verify <id> --status verified --source <url>`
4. **사람 (제작)** 브리프의 30초 구조 템플릿으로 **원본 없이** 한국 이야기를 씀 → 촬영/편집 → 업로드
5. **사람 (1분)** `radar publish-log <id> --url <내 영상 URL>` → 다음 브리프에서 제외, 성과 비교 기준 생성
6. **주 1회** YouTube Studio 조회수·구독 전환을 보고 `radar judge --import` 로 사람 판단 추가 → 가중치 보정 근거

## 첫 주 소재 (2026-10-08 리포트 기준, 검증 상태는 브리프 참조)

1. **가족 비밀 암호** — AI 음성 복제 사기 vs 가족 암호. FBI PSA(2024-12-03)·FTC 확인됨. 한국형: 경찰청 딥보이스 주의보 + "우리 집 암호 정하기" 포맷.
2. **클릭 없이 뚫리는 폰** — 제로클릭 스파이웨어. Citizen Lab(2025-03)·Apple 위협 알림 페이지 확인됨. **주의**: 표적은 언론인·활동가. "일반인은 표적이 아니지만 대비는 이렇게"로 정직하게.
3. **가짜 상사 영상통화** — 딥페이크 CFO 사기(홍콩 Arup, 약 340억 원, 2024-02). 한국형: 중견기업 재무팀 + 유선 역확인 규칙.
4. **에어비앤비 AI 사진 사기** — AI 조작 사진으로 손해배상 청구. 미국 보도 확인, 한국형: 국내 숙박앱 분쟁 절차.
5. **아이가 '당첨' 팝업을 누르면** — 아동 소액결제·사기. 부모 대상. 한국형: 서울시 소액결제 안내 + 한 줄 규칙.

## 도구가 추가로 할 일 (이 저장소)

- `radar brief` (완료): 검증 우선 상위 N개 제작 브리프
- `radar publish-log` (완료): 제작 기록 → 브리프 중복 방지, 성과 피드백 기준
- 다음: 제작 영상의 YouTube Studio 지표를 기록하는 `radar outcome` → Winner/Loser → 가중치 학습 (로드맵 6)

## 솔직한 리스크

- 30일 1,000명은 신규 채널 기준 상위권 성과입니다. 도구는 소재 선택의 실패 확률을 줄이지, 성공을 보장하지 않습니다.
- Shorts 알고리즘은 초반 1~2주 노출이 불규칙합니다. 2주차 지표로 판단하고 1주차 숫자에 과잉 반응하지 않습니다.
- 사실 확인 없이 "사건"을 단정하면 신뢰를 잃습니다. 검증 안 된 소재는 "이런 수법이 보고됐다"로만 씁니다.
